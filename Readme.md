Budget Rectifier

Budget Rectifier is a modern Web Application that helps users efficiently track daily expenses, manage monthly budgets, and gain meaningful insights into their spending habits. Built with Next.js, TypeScript, Tailwind CSS, and Supabase, the application provides a fast, secure, and responsive personal finance management experience.

🚀 Features
🔐 Secure Authentication using Supabase Auth
💸 Add, edit, and delete daily expenses
📅 Automatic transaction date management
📂 Custom expense categories
📊 Interactive dashboard with spending analytics
📈 Category-wise expense breakdown
💰 Set and update monthly budget
📆 Navigate and view previous months' transactions
🤖 Budget Rectifier with personalized spending recommendations

⚡ Fast, responsive, and user-friendly interface

⚙️ Installation

Clone the repository

git clone https://github.com/yourusername/budget-rectifier.git

Navigate to the project

cd budget-rectifier

Install dependencies

npm install

Create a .env.local file

NEXT_PUBLIC_SUPABASE_URL=your_supabase_url

NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

Run the development server

npm run dev

Open
http://localhost:3000
